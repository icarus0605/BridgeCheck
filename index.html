1. 코드와 명세 넣기

파일은 이 브라우저에서만 처리합니다. 서버에 전송하거나 자동 보관하지 않습니다. 새로고침 전 일정표를 저장하세요.

플랫폼별 최대 100개, 파일당 1MB, 전체 코드 5MB. 테스트 파일과 빌드 산출물은 제외됩니다.

어떤 코드를 찾나요?

Android의 @JavascriptInterface 메서드, Swift의 message.name 및 Android·Swift의 action/command/method 리터럴 비교 및 switch/when 분기, React의 callBridge/invokeBridge·window.Android·postMessage action, sendEvent/emit/emitEvent 발신과 addEventListener/on 수신의 리터럴 이름을 찾습니다.

이 패턴은 브리지 참조 후보이며 등록·실제 호출 경로를 보장하지 않습니다. Swift WK 채널 등록만으로 기능 구현을 판정하지 않습니다. 정규식/나눗셈 기호·템플릿·raw·다중행 문자열을 포함한 파일은 보수적으로 제외하며 분석 범위에 표시합니다. 다른 객체 별칭, 동적/조합/이스케이프 이름, Objective-C, 문자열 내부 JavaScript, 필드·타입·조건·콜백 의미는 확인할 수 없습니다. 실제 브리지 파일을 직접 선택해 주세요.
