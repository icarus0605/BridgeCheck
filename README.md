# BridgeCheck

Android·iOS·React Bridge 코드와 명세의 **이름 참조 후보**를 대조하고, 담당자별 수정 일정 엑셀로 전달하는 로컬 처리 도구입니다.

- 실행: https://bridgecheck.vercel.app/
- 코드: Android Kotlin/Java, iOS Swift, React JS/JSX/TS/TSX. 명세서는 필수이며, 세 플랫폼 중 코드 파일 하나 이상이면 점검합니다. 미업로드 플랫폼은 미검증으로 표시하고 결과·일정 행을 만들지 않습니다. 플랫폼별 여러 파일 선택도 지원합니다.
- 명세: XLSX/CSV에서 시트·기능명·응답 이벤트 열 선택, 또는 JSON의 action/responseEvent. 엑셀 양식 다운로드 제공.
- 결과: 발견 근거 파일·행, 미발견/유사 이름/명세 외 후보, 검토 시작 위치와 제안. 선택한 한 항목의 상세만 표시.
- 일정: 담당자·수정 내용·개발/QA/운영 예정일·진행 상태. 엑셀 다운로드→수정→미리보기→확인 후 반영.
- 담당자 목록: 이름을 추가하고 항목마다 목록에서 선택합니다. 빈 이름과 대소문자만 다른 중복은 막고, 담당자별·미지정 건수와 해당 항목만 보기를 제공합니다. 기존 입력과 엑셀에서 불러온 담당자도 목록에 반영합니다. 목록과 일정은 탭 메모리에만 있어 새로고침하면 사라지며, 엑셀에는 배정된 담당자만 저장됩니다.
- 공유폴더: 데스크톱 Chrome/Edge에서 PC가 접근 가능한 폴더를 직접 선택. 담당자 하위폴더에 고유 파일명 XLSX 저장. 미지원 브라우저는 다운로드 후 직접 공유폴더로 이동.
- 기존 이전↔새 JSON 계약 비교는 `contracts.html`에 보존했습니다.

## 분석 범위

범용 컴파일러·실행 테스트·AI 코드 의미 분석기가 아닙니다. 이름 발견도 구현 완료나 통과를 뜻하지 않습니다. 명세 필드·자료형·요청/응답 내용은 점검하지 않습니다. 제한된 리터럴 호출/분기 패턴만 근거로 표시하며 실제 등록과 호출 경로는 사람이 확인합니다.

동적/조합/이스케이프 이름, Objective-C, 별칭, 문자열 안 JavaScript는 지원하지 않습니다. 정규식/나눗셈·템플릿·raw·다중행 문자열, 닫히지 않은 문자열/주석이 있는 파일은 보수적으로 분석 제외하며 화면·보고서에 사유를 표시합니다. JSX 닫힘 기호는 허용합니다. 실제 코드 표본으로 지원 패턴을 추가해야 합니다.

업로드 파일을 실행·외부 전송·영구 보관하지 않습니다. 결과 보고서에 원문 코드는 넣지 않지만 기능명·파일명·담당자명은 포함되므로 공유 대상은 사용자가 선택합니다. 공유폴더는 브라우저가 선택한 경로에 쓰는 기능이며 서버 저장·공동 편집·자동 동기화 기능이 아닙니다.

## 개발과 검증

```sh
python3 -m http.server 8769 --bind 127.0.0.1
node scripts/harness.cjs check
node scripts/harness.cjs status
```

발표용 시연 세트는 `samples/demo/`입니다. `1_Bridge명세.xlsx`와 세 코드 파일을 올려 점검한 뒤 `2_담당자_일정_불러오기용.xlsx`를 불러오면 담당자 목록과 일정이 채워집니다. `node scripts/make-demo-samples.cjs`로 엑셀을 다시 만들 수 있습니다. 3장 발표 자료는 `output/pdf/bridgecheck-presentation-3p.pdf`입니다.

`samples/codecheck/`는 의도적으로 getLocation 네이티브 처리가 빠진 정적 점검용 예제입니다. 컴파일 가능한 앱 프로젝트가 아닙니다. 예제 버튼으로도 같은 흐름을 체험할 수 있습니다.

기존 계약 회귀검사, 새 코드점검·엑셀·폴더 저장 테스트, 하네스 상태검사를 실행합니다. 브라우저 및 Claude 교차검토 증거는 `docs/05-implementation-check.md`에 기록합니다. 실제 OS 공유폴더 권한과 서버 동기화는 별도 사용자 환경 검증이 필요합니다.

SheetJS CE 0.20.3은 공식 `https://cdn.sheetjs.com/xlsx-0.20.3/package/dist/xlsx.full.min.js`에서 가져와 자체 호스팅합니다. 라이선스는 `scripts/codecheck/vendor/LICENSE`에 있습니다.
