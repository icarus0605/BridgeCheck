# 04. 교차검토 기록

## 1. 2026-10-23 검토 요지와 출처

아래는 주인님이 이번 저장소 구성 요청으로 전달하신 오늘의 Claude·Codex 교차검토 요지입니다. 이 저장소 작성 과정에서 Claude의 새 응답을 직접 받거나 동일 최종 파일에 대한 양쪽 무수정 합의를 새로 확인한 기록은 아닙니다.

Claude의 코드 생성안과 Codex의 변경 영향 점검기안을 비교했습니다. 이번 방향은 최신 웹과 구버전 앱 사이의 계약 변경 영향을 보여주는 점검기이며, 코드 생성은 후속 범위입니다. Claude는 “컴파일 오류”라는 주장을 철회했습니다. 이 도구는 소스 분석이나 컴파일을 수행하지 않으므로 컴파일 오류를 판정하지 않습니다.

## 2. 규칙표 보완 6건

| 번호 | 보완 내용 | 현재 요구사항 반영 |
| --- | --- | --- |
| 1 | 필드 삭제 필수/선택 분기 | 요청 필드 삭제는 구계약 필수이면 오류, 선택이면 계약상 호환 |
| 2 | 응답 필드 삭제 확인 필요 | 신웹 응답 파서의 미지 키 처리 정책에 따라 판정 |
| 3 | 필수→선택 추가 | 요청은 생략 가능해 오류 가능, 응답은 호환 |
| 4 | 오류 정의 한정 | 장애 확정이 아니라 계약상 비호환 가능성 검출 |
| 5 | 미지 키 처리 선택지 단순화 | 각 수신 파서에 무시/거부/미확인(기본)만 제공 |
| 6 | 구웹 조합 제외 | 최신 웹 × 구버전 앱만 점검하고 화면·보고서에 제외 범위 표시 |

## 3. 반영 위치와 검토 한계

위 결정은 [PRD §3–5](02-prd.md#3-입력과-비교-설정), [컨텍스트 §2](03-context.md#2-유지변경한-결정), 작업 프롬프트에 반영합니다. 이번 회차는 문서와 샘플 준비이며 제품 실행·실기기·배포 검증은 미수행입니다. 본 최종 파일의 새 Claude 교차검토 완료를 주장하지 않습니다.

2026-10-22 1차 안의 원문 검토 기록은 [legacy](legacy/웹뷰-브리지-교차검토기록.txt)에 보존합니다. 그 기록의 최종 합의는 당시 1차 안에 대한 것이며 변경된 제품이나 현재 파일에 대한 합의로 확대하지 않습니다.
